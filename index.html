Дипломный проект · 2026

SynektaKZ

Платформа, где стартапы Казахстана находят друг друга для коллабораций. Каждый проект описывает, что ему нужно и что он может предложить, а система подбирает партнёров, у которых эти запросы и предложения сходятся. Сравнение идёт по смыслу, а не по ключевым словам.

  • Запросы и предложения проекта превращаются в 384-мерный вектор мультиязычной моделью MiniLM (Hugging Face), поиск идёт по HNSW-индексу в pgvector.
  • LLM (LLaMA 3.1 через Groq) объясняет, чем два проекта полезны друг другу и где точки взаимодействия.
  • Запросы на коллаборацию с уведомлениями в реальном времени через Supabase Realtime.
  • Контакты открываются только после взаимного согласия: это реализовано SQL-функциями SECURITY DEFINER и политиками RLS.
